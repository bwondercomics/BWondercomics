
THE BWONDERCOMICS READER

MISSION STATEMENT:

Build a self hosted comic platform toolkit that lets creators launch a full webcomic site on their own server
with zero drama. It should handle the boring stuff automatically (publishing, archives, navigation, scheduling,
performance, security) while staying flexible enough to match any comic format, branding style, and
workflow. The goal is simple: give creators the control of an independent website with the convenience and
features of a modern comic host, without relying on a central platform.



ADMIN/CMS

	Secure admin panel

	Roles/permissions (multi-author support)

	Content editor for posts/pages

	Scheduling/queue system

COMIC FORMATS

	Page-by-page mode

	Vertical infinite-scroll mode

	Chapter/volume organization

	Archive view (by date, chapter, volume)

READER NAVIGATION

	Next/Prev/First/Latest buttons

	Chapter navigation

	Jump-to-page/episode

	Mobile-friendly paging controls

	2-page spread support (your core differentiator)

SITE PAGES (BUILT-IN)

	Home

	Latest

	Archive

	Cast/characters

	About

	Gallery

	Blog/news

MEDIA SUPPORT

	Image uploads (common formats)

	Optional audio/video embeds

	Creator notes under episodes

	Markdown support for notes/transcripts

CUSTOMIZATION

	Theme system (templates + CSS)

	Full HTML/CSS override option

	Theme builder or theme marketplace (optional)

	Custom domains + white-label branding

COMMUNITY

	Comments per episode/page

	Comment moderation tools

	Reader accounts (optional)

	Likes/reactions (optional)

DISCOVERY AND RETENTION

	RSS feeds

	Social sharing + rich link previews (OpenGraph)

ACCESSIBILITY

	Transcripts/alt text per page

MIGRATION/IMPORT

	Batch upload tools
